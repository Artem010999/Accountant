## Решения владельца: как выполнено

**1. Состояния (429, 402, BLOCKED_PROJECT_SWAP) на /files.**
- Инлайн-карточка `shared/ui/Notice/` (tsx, css, test), экспорт добавлен в `shared/ui/index.ts` (одна строка). Три тона на токенах: `warning` → `--color-warning-bg` / `--color-warning-text` (лимит); `info` → `--color-info-bg` / `--color-info-text` (пейволл); `danger` → `--color-danger-bg` / `--color-danger-text` (блокировка). Радиус карточки `--radius-card`, отступы и шрифты токенами, кнопка действия — пилюля на `--color-brand` (как кнопки баннера States). Единственное локальное значение: радиус 10px и размер 40×40 у кнопки «Закрыть» (как у тоста), помечено в CSS.
- Тост оставлен. Его текст не менялся, кроме ссылки 402: «Подключить за 990 ₽» → «Тарифы», для единообразия с карточкой.
- **402:** экран берёт `planFeatures(plan.features).ai_parsing` из `shared/config/flags.ts`. Если функция выключена, зона загрузки заменяется карточкой пейволла, загрузка не отправляется (тост 402). Проп `aiParsingEnabled` переопределяет значение (имитация выключенного флага). При `ALL_FEATURES_ENABLED = TRUE` карточка в приложении не показывается. Тест: `aiParsingEnabled={false}`, API не вызывается.
- **429:** лимит берётся из `shared/data/plans.ts` (`file_uploads_limit`: «Профессиональный» 10, «Премиум» 50). Лимит передаётся в `FilesApi.upload` (`fileLimit`). Карточка «Лимит файлов исчерпан» показывается, когда число файлов достигло лимита. Проверка дубля по sha256 идёт раньше лимита (дубль не занимает место).
- **BLOCKED:** тост как раньше плюс карточка `danger`, закрывается кнопкой «Закрыть».
- Кнопка пейволла — «Тарифы», ведёт на `/billing` ссылкой (окно не делалось).
- Проп `plan` (по умолчанию `'pro'`) выбирает тариф: по умолчанию как в эталоне (Профессиональный, 10 файлов). Тест: `plan="premium"` даёт «из 50» и `aria-valuemax=50`.

**2. Профиль: валидация.**
- Текст ошибки под полем, связан через `aria-describedby`, цвет `--color-danger-text`, размер `--fs-14`. Поле получает `aria-invalid` и рамку `--color-danger-text`. Ошибка исчезает при вводе.
- Поля: телефон (обязательный) и вуз (обязательный при обучении). Других полей с валидацией в эталоне нет: ФИО заблокировано (замок и пояснение, как в эталоне), e-mail только показывается. Telegram, уровень, курс и регион без проверки, как и раньше.
- Тесты: ошибка телефона появляется и исчезает; ошибка вуза; при «Не учусь» ошибки вуза нет.

**3. Плейсхолдеры и прототипные элементы.**
- В `Files.dc.html`, `States.dc.html`, `Profile.dc.html` нет элементов, помеченных как «прототип». Ничего не удалено и не скрыто; флаги не менялись.
- Оставлены как в эталоне кнопки-заглушки без действия (вопрос 2).
- Hex-цвета в SVG `Profile.tsx` (5 штрихов) заменены на `currentColor`, цвет задан классами с токенами в `Profile.css`. Вид не изменился (0 px по состояниям просмотра).
- Подпись «Скачать»/«Открыть» без изменений (G5).

**4. Прочее.** Хранилища нет: «Скачать» остаётся тостом «Скачивание началось.», «Открыть» показывает макет эталона (G5).

## Вопросы владельцу

1. **Тариф по умолчанию для /files.** В `flags.ts` `DEFAULT_PLAN_ID = 'premium'`, но эталон Files показывает «Профессиональный» (10 файлов). Сейчас по умолчанию `'pro'`, чтобы совпасть с эталоном. Если по умолчанию должен быть «Премиум», эталон (заголовок «Тариф», «из 10») не совпадёт.
2. **Кнопки-заглушки без действия.** В States: «Написать в поддержку» и «Связаться с поддержкой» ведут на `href="#"`. В Profile: «Ошибка в ФИО? Напишите в поддержку» — кнопка без действия. Оставить как в эталоне, скрыть или убрать?
3. **Цвет текста select.** В эталоне текст select чёрный (браузерный по умолчанию), у нас `--color-ink` (`#17171C`). Принять токен (разница 23 единицы, ниже порога) или ввести локальное значение `#000` для select?
4. **Тексты карточки лимита.** Я придумал текст и кнопку «Тарифы» для карточки лимита (для тарифа «Профессиональный» и «Премиум»). Оставить, или карточка лимита без кнопки?
5. **Синий тон «информация».** Пейволл сделан тоном `info` на токенах `--color-info-*` (синий, из DesignSystem «Статусы»). Если нужен фирменный персик (`--color-peach`), скажите.
