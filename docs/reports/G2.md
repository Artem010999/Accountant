## Оговорки и техдолг (переходят в G2.5 / G5)

1. **Временные копии эталонов.** Эталоны без support.js не разворачиваются. Все V1-сравнения сделаны с копиями, собранными из `renderVals` самих эталонов (scratchpad). design/ не менялся.
2. **Значения вне tokens.css.** Помечены комментарием `/* вне токенов */` в CSS модулей G2. Перечень — в отчётах групп. Их нужно перенести в tokens.css без изменения вида.
3. **Отступы кабинета.** CabinetLayout даёт 28/32/56, эталоны Gaps/Result — 36/48/64 и gap 28. Сделано через CSS-переменные `--cabinet-main-padding` и `--cabinet-main-gap` по маршруту.
4. **Favicon.** Нет иконки в index.html → 404 на /favicon.ico. Нужна иконка или `<link rel="icon" href="data:,">`.
5. **Заголовок вкладки.** index.html: «Конструктор Паспорта Проекта»; в эталонах у каждого экрана свой `<title>`. Нужно задавать title по маршруту.
