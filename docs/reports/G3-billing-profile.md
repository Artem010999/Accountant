## Блокер V1: блок тарифа в сайдбаре (шелл G2)

- Что: `CabinetLayout` всегда рендерит `cabinet__plan` (блок тарифа с полоской). Эталоны Billing и Profile его не содержат.
- Эффект: лишний элемент на каждом состоянии обоих экранов (около 2000–2300 px), по критерию V1 это недопустимо.
- Почему не исправлено: шелл принадлежит G2, по правилам задачи его не правим.
- Что сделать (нужно решение владельца шелла и согласие на правку): в `CabinetLayout` добавить флаг маршрута (например `showPlan: false` для `/billing` и `/profile` в `ROUTE_SHELL`). Тот же механизм нужен для данных тарифа: после окончания подписки шелл показывает «Профессиональный», хотя экран показывает «Базовый» (проверено: при `currentPlan="basic"` в сайдбаре остаётся старый тариф).
- Стоит проверить и остальные экраны кабинета (Files, States) на наличие блока тарифа в их эталонах. Это вне G3.
