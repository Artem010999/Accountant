Решения владельца, применённые в последнем раунде:
- Статистика: счётчики считаются суммированием по данным пользователей; «Всего» — общее количество.
- Журнал пользователей: дата и время в формате ДД.ММ.ГГГГ ЧЧ:ММ из данных событий; разблокировка пишется.
- База знаний: допустимы PDF и DOCX, лимит 50 МБ; предыдущая версия переходит в «Архив», когда новая вступает в силу; подсказка без упоминания JSON.
- Страж: порог ошибки только при block > warn; название проекта — «Проект <название>».
- Платежи: без демо-значений в сводке, показываются «—»; фильтр по статусу оставлен.

Подтвердить владельцу (агент сделал по своей интерпретации):
- Демо-файлы в базе знаний переименованы с `.json` на `.docx`, так как JSON не должен упоминаться на экране.
- Счётчики статистики реализованы через сумму вкладов (reduce); результат тот же.
