## Остаточные расхождения

1. **Счётчик «Пробелы» в меню кабинета (блокер V1).** `CabinetLayout.tsx` выводит `gapsCount` с значением по умолчанию `DEFAULT_GAPS_COUNT = 1` на всех кабинетных маршрутах. Эталон `Gaps.dc.html` показывает `5 − закрыто` (сейчас «3»), эталон `Result.dc.html` счётчика не показывает. Нужно: передавать счётчик из состояния экрана (например, через контекст или параметр маршрута) и не показывать его на `/result`. Файлы: `shared/layout/CabinetLayout.tsx`, `app/routes.tsx`. Владелец: агент Passport / общий слой. Экраны G2 не могут это исправить без выхода из зоны владения.
2. **Отступы оболочки (техдолг, не расхождение).** `CabinetLayout.css` задаёт `main` с отступами 28/32/56 и `gap` 20 (это оболочка Passport.dc.html). Эталоны Gaps и Result задают 36/48/64 и `gap` 28. Компенсация: корневые `.gaps` и `.result` имеют отрицательные поля `calc(var(--space-28) * -1) calc(var(--space-32) * -1) calc(var(--space-56) * -1)` и собственные отступы 36/48/64. Если оболочка станет настраиваемой по маршруту, компенсацию надо убрать. Такой же техдолг у любого экрана с отступами 36/48/64 (Files, Billing, Profile).
3. **`<title>` эталона.** В эталонах: «Буха — пробелы и новизна» и «Буха — итог проверки». У приложения `document.title` общий (`index.html`: «Конструктор Паспорта Проекта») и не меняется по маршруту. Это общий слой, в V2 засчитано как 5 отсутствующих строк.
4. **favicon 404 (T4).** `index.html` не задаёт иконку, браузер запрашивает `/favicon.ico`, получает 404 и пишет ошибку в консоль на `/gaps`. Исправление общее: `<link rel="icon" href="data:,">` в `index.html`. Файл не трогал, так как он вне зоны G2.

## Расхождения с постановкой и вопросы к владельцу

1. **Текст кнопки новизны.** В задании: «Продолжить без этого». В эталоне: «Продолжить без сравнения». Взят текст эталона.
2. **Переключатель «Прототип: Допуск / Уточнить / Стоп»** есть в `Result.dc.html`, оставлен как в дизайне. Нужно решить, остаётся ли он в продукте. В продукте статус должен приходить с бэкенда.
3. **Закрытие пункта новизны.** В эталоне нет действия, которым пункт «Сравнение с аналогами» закрывается. Кнопка «Продолжить без сравнения» только ведёт на `/result`, поэтому «Закрыто N из 5» не достигает 5. Нужна логика от продукта.
4. **Кнопки «Скачать DOCX» и «Скачать PDF»** выведены, обработчиков нет (экспорта в API ещё нет). «Согласовать паспорт» меняет только локальное состояние.
5. **«Проверить сравнение»** по эталону только увеличивает счётчик попыток, валидации нет. Реализовано так же.
