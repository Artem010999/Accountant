5. `main` получает отступы и gap через CSS-переменные `--cabinet-main-padding` / `--cabinet-main-gap`. Запасные значения в CSS — прежние токены (28/32/56, 20), `/passport` не изменился.

## Открыто и не сделано

1. **Счётчик «Пробелы» на `/gaps`** (блокирует V1 шелла на `/gaps`). Экран Gaps должен вызвать `useCabinetShell({ gapsCount: openCount })`. Без этого на `/gaps` показывается `1` вместо `3`. Файл Gaps.tsx — зона G2-B, я его не менял.
2. **`favicon.ico` → 404** на dev-сервере. CDP-съёмка фиксирует `Failed to load resource: 404` на каждой загрузке, потому что браузер запрашивает `/favicon.ico`, а в `frontend/index.html` нет иконки. Инструмент `read_console_messages` эту запись не показывает, поэтому T4 по нему зелёный. Исправление: `<link rel="icon" href="data:,">` в `frontend/index.html`. Файл общий, я его не менял, нужно решение координатора.
3. **Заголовок вкладки**: `frontend/index.html` даёт «Конструктор Паспорта Проекта», в эталоне «Буха — паспорт проекта». Тоже общий файл, не менял.
4. **Кнопки без обработчиков**, как в эталоне: DOCX, PDF (экспорт, F11), «Привязать документ», «Убрать из паспорта» (F9 п.3). В дизайне обработчиков нет.
5. **Правка поля повторяет эталон**: «Сохранить» помечает поле правленым и снимает согласование, введённый текст не применяется; для «Продажи и пилоты» после правки показан `editedSegs`. Пересчёт спанов — задача бэкенда (F9 п.5). Вопрос к дизайну: должна ли правка менять текст поля на экране?
6. **Черновик правки «Продажи и пилоты»** стартует с фиксированного `editText` эталона, а не с текущего текста — повторено как в эталоне.
7. В тестах React Router выводит `Future Flag Warning` (`console.warn`) из-за `MemoryRouter` без флагов будущих версий. Ошибок `console.error` нет; в браузере эти предупреждения не видны.
8. Счётчик у «Пробелов» помечен `aria-hidden`, поэтому имя ссылки остаётся «Пробелы». Программы чтения экрана количество не получают.
