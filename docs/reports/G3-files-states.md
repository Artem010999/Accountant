## Что сделано

**Files (`/files`):** шапка, три карточки (файлы, объём, тариф), таблица с действиями, зона загрузки (клик и перетаскивание). Загрузка: sha256 содержимого файла в браузере (`crypto.subtle`). Дубль по sha256 → «уже загружен», место в лимите не занимает. Файл с тем же именем и другим хешем → новый источник. Лимит 10 → 429-тост. Статусы 402 (тост с переходом на `/billing`) и BLOCKED_PROJECT_SWAP (тост, файл не сохраняется) приходят через внедряемый `FilesApi`. Просмотр (drawer), удаление с подтверждением «Оставить / Удалить файл», тост «Файл удалён» со ссылкой на `/passport` при наличии утверждений. Тесты: 13 (рендер, загрузка, дубль, одинаковое имя с другим хешем, лимит, 402, BLOCKED, добавление через диалог, просмотр, удаление с отменой и подтверждением, скачивание, закрытие тоста).

**States (`/states`):** пять состояний из эталона, без бокового меню, сетка 2 колонки, баннер на всю ширину. Ссылки и подписи дословно. Тесты: 7 (заголовок, пять подписей, ссылки по состояниям).

Оболочка `/files` задаёт отступы через существующий `useCabinetShell` (36px 48px 64px, gap 28px): правка `CabinetLayout` не понадобилась, кроме R1.
